# ADR-17: HTML 내보내기 — SvelteFlow SVG 인라인

- **날짜**: 2026-04-13
- **문제**: E2 독립 HTML 내보내기는 "단일 파일 + < 500KB + 드릴다운 지원"을 요구. 풀 인터랙티브 그래프 라이브러리를 번들링하면 500KB 초과
- **검토 대안**:
  - (A) 현재 SvelteFlow 렌더 결과를 SVG로 캡처 → HTML에 인라인, 미니멀 JS로 pan/zoom + 레벨 전환
  - (B) cytoscape.js(~400KB) 전체 번들링 + 그래프 데이터 인라인 → 풀 인터랙티브
  - (C) vis-network(~600KB) 번들링 → 500KB 목표 초과
- **결정**: 옵션 A 채택. 드릴다운된 각 레벨을 사전에 SVG로 캡처하고 버튼으로 표시 전환. pan/zoom만 가벼운 JS 처리
- **기각 이유**: B는 추가 의존성 400KB로 빡빡, C는 목표 초과. 인터랙티브 편집이 아닌 "읽기 전용 문서" 용도이므로 인터랙션 축소가 합리적
- **결과**: `htmlExporter.ts` — SvelteFlow 뷰포트 SVG 직렬화 + 레벨별 스냅샷 인라인. 외부 CDN 의존 0, 단일 파일 오프라인 배포
- **참조**: TASK-E2-html-export.md
