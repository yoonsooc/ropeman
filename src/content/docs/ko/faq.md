Ropeman을 처음 써 보는 분들이 가장 많이 묻는 질문을 모았습니다. 여기서 답을 찾지 못했다면 [문제 해결](/docs/ko/troubleshooting) 문서도 함께 살펴보세요.

## 보안과 데이터

### 제 프로젝트의 원본 소스 코드가 외부 서버로 유출되나요?

아니요. AI에는 코드 구조 요약(파일 경로, 심볼 이름, import)을 보내고, 파일 원문은 보내지 않습니다. 요약이 어디로 가는지는 AI 모드에 따라 다릅니다.

- **WebGPU 모드** — 모델이 기기 안에서 돌기 때문에 아무것도 밖으로 나가지 않습니다.
- **데모·API 키 모드** — 요약이 AI 제공자에게 갑니다. 데모 요청과 Anthropic·OpenAI 키 요청은 Ropeman 프록시를 거치고, Gemini 키 요청은 Google로 바로 갑니다.

### 입력한 API 키는 안전하게 보관되나요?

Ropeman 서버는 API 키를 저장하지 않습니다. 키는 이 브라우저의 **로컬 저장소(localStorage)**에만 있습니다.

- **API 키 모드** — AI를 호출할 때마다 요청에 키를 담아 보냅니다. Gemini 요청은 Google로 바로 가고, Anthropic·OpenAI 요청은 Ropeman 프록시를 거칩니다. 프록시는 키를 저장하지 않습니다.
- **WebGPU 모드** — 키가 필요 없습니다.

**설정 → 초기화** 버튼이나 브라우저 사이트 데이터 삭제로 언제든지 지울 수 있습니다.

### 회사 기밀 프로젝트에 써도 되나요?

보안 요구가 가장 엄격하다면 **WebGPU** 모드를 권장합니다. 이 모드는 Ropeman 인프라를 거치지 않습니다. 데모 요청과 Anthropic·OpenAI 키 요청은 Ropeman 프록시를 거치고, 프록시는 요청 본문을 저장하지 않습니다. Gemini 키 요청은 Google로 바로 갑니다. 자세한 내용은 [보안 문서](/docs/ko/security)를 보세요.

### 상업적으로 이용할 수 있나요?

상업 프로젝트 분석에도 Ropeman을 쓸 수 있습니다. 다만 데모 모드에는 공정 사용 한도가 있으니, 업무에 계속 쓰려면 API 키 모드를 권장합니다.

## 지원 범위

### 어떤 프로그래밍 언어를 지원하나요?

**Python, JavaScript, TypeScript, Go, Rust, Java, C, C++, Ruby, PHP, Swift, Kotlin, C#, Scala**를 지원합니다. 파일 확장자로 자동 감지됩니다.

### 프로젝트 크기에 제한이 있나요?

파일 수 **최대 2,000개**, 개별 파일 **최대 500KB** 까지 지원합니다. 대규모 프로젝트는 설정의 **코드 구조 요약 크기 제한**을 조절해 AI 전송 한도를 맞추세요(기본 250KB).

### 어떤 브라우저에서 동작하나요?

- **Chrome, Edge 등 Chromium 기반 브라우저 권장** — File System Access API를 완전히 지원합니다.
- **Firefox / Safari** — 드래그 앤 드롭 폴더 업로드로 제한적 사용이 가능합니다.
- **WebGPU 모드** 는 WebGPU를 지원하는 최신 브라우저에서만 동작합니다.

### 완전 오프라인으로 쓸 수 있나요?

WebGPU 모드는 모델을 처음 내려받은 뒤에는 오프라인에서 동작합니다. 데모와 API 키 모드는 인터넷 연결이 필요합니다.

## 사용 방법

### 분석 결과가 저장되나요?

예. 분석 결과는 브라우저에 자동으로 캐시되어, 같은 프로젝트를 다시 열면 AI 재호출 없이 즉시 복원됩니다. 설정의 **분석 캐시** 토글로 이 동작을 켜고 끌 수 있고, **캐시 초기화** 버튼으로 직접 지울 수 있습니다.

### 드릴다운이란 무엇인가요?

다이어그램의 한 영역(예: "API 레이어")을 더블클릭하면 AI가 **해당 영역 내부의 구조**를 다시 분석해 새로운 하위 다이어그램을 생성합니다. 원하는 깊이까지 반복적으로 파고들 수 있습니다.

### 파싱 에러가 나면 어떻게 해야 하나요?

특정 파일에서 파서가 실패하면 해당 파일만 건너뛰고 나머지 파싱은 계속 진행됩니다. 브라우저 개발자 도구 콘솔에서 어떤 파일이 실패했는지 확인할 수 있습니다. 자세한 대응은 [문제 해결](/docs/ko/troubleshooting) 문서를 참고하세요.

### GitHub URL로 분석할 수 있나요?

네. 랜딩 페이지에서 공개 GitHub 저장소의 URL을 입력하면 로컬에 프로젝트를 다운로드하지 않고도 바로 분석할 수 있습니다. 비공개 저장소는 지원되지 않습니다.

### 분석 결과를 공유할 수 있나요?

네. AI 분석이 완료된 후 헤더의 **공유하기** 버튼을 누르면 공개 링크가 만들어집니다. 이 링크로 다른 사람에게 분석 결과를 보여 줄 수 있습니다. 링크는 14일 동안 유지됩니다.

### 내 Claude Code나 Gemini CLI를 쓸 수 있나요?

메인 앱에서는 쓸 수 없습니다. [ropeman.dev/bridge](https://ropeman.dev/bridge)의 브리지 모드가 내 컴퓨터의 `ropeman serve`에 연결합니다. 위쪽 단계는 코딩 에이전트가 이름을 붙입니다. 내가 여는 폴더의 부분에는 헤드리스 `claude` 일꾼이 이름을 붙입니다. 일꾼 CLI가 없으면 내가 다음 메시지를 보낼 때 에이전트가 이름을 붙입니다. serve는 `--cli gemini`를 줄 때만 `gemini`를 씁니다. 방법은 [브리지 설정](/docs/ko/bridge-setup)에 있습니다.

### Ropeman은 어떻게 설치하나요?

설치는 필요 없습니다. [https://ropeman.dev](https://ropeman.dev)에 접속하면 바로 사용할 수 있습니다.

### 특정 디렉토리를 분석에서 제외할 수 있나요?

네. Settings → **추가 제외 디렉토리** textarea에 디렉토리 이름을 1줄 1개씩 입력하면 기본 제외 목록(node_modules, .git, tests 등)에 추가됩니다. Rust의 `target`, 생성된 코드가 있는 `generated`, 모노레포의 `third_party` 같은 대형 디렉토리를 분석 대상에서 빼고 싶을 때 유용합니다. 설정은 브라우저에 저장되며 다음 프로젝트 로드부터 적용됩니다.

### 진행 중인 분석을 취소할 수 있나요?

네. 오른쪽 아래 진행 상태 표시의 **취소** 버튼으로 언제든 멈출 수 있습니다. 확인 창에서 "다시 묻지 않기"를 고르면 다음부터는 바로 취소됩니다. 취소는 데모, API 키, WebGPU 세 AI 모드 모두에서 동작합니다. 다른 페이지로 옮겨도 분석은 계속되고 진행 상태 표시도 그대로 보입니다. 탭을 닫거나 새로고침하면 분석이 멈추므로, 그 전에 브라우저가 경고를 띄웁니다.

### 여러 영역을 동시에 분석할 수 있나요?

네. 다이어그램의 서로 다른 노드를 각각 더블클릭하면 드릴다운 분석이 병렬로 진행됩니다. 각 분석은 별도의 pill로 표시되고 개별 취소가 가능합니다. 3개를 초과하면 "N개 분석 중" 그룹 배지로 자동 병합되고, 펼치기 아이콘(^)으로 목록을 열어 개별 요청을 확인할 수 있습니다. 탭을 잠시 다른 곳에 둬도 완료 시 **브라우저 알림**(권한 허용 시)으로 결과를 받을 수 있습니다.
