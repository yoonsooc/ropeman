Ropeman에서는 **AI 트랙 세 가지** 중 하나를 고릅니다. 모드마다 비용, 성능, 보안, 설정 난이도가 다르니 목적에 맞는 트랙을 고르세요.

## 데모

가장 빠르게 체험할 수 있는 무료 모드입니다.

- **특징** — 회원가입이나 API 키 없이 즉시 사용 가능합니다. 요청 횟수와 프로젝트 크기에 완만한 제한이 있습니다.
- **요구사항** — 없음. 브라우저만 있으면 됩니다.
- **데이터 흐름** — 브라우저가 **코드 구조 요약**(기본 250 KB 한도)을 Ropeman 데모 Worker로 보내고, Worker가 Google Gemini API로 넘깁니다. 원본 소스 코드는 보내지 않습니다.
- **무료 등급 안내** — 데모는 Google Gemini API 무료 등급에서 처리합니다. 무료 등급에서는 Google이 입력과 응답을 서비스 개선에 쓸 수 있습니다. 공개하기 어려운 코드라면 API 키나 WebGPU 모드를 쓰세요.
- **추천 상황** — 처음 Ropeman을 써 보는 경우, 빠르게 데모를 보여줘야 하는 경우, 중소형 프로젝트 체험.

## API 키 (BYOK)

본인의 LLM API 키를 쓰는 Bring Your Own Key 방식입니다.

- **특징** — Google Gemini, Anthropic Claude, OpenAI GPT 중 원하는 공급자를 선택해 더 강력한 모델을 사용할 수 있습니다. 속도 제한은 해당 공급자 계정 기준으로 적용됩니다.
- **요구사항** — 하나 이상의 LLM API 키. 키는 **브라우저 localStorage**에만 저장되고, Ropeman 서버에는 저장되지 않습니다.
- **데이터 흐름** — Gemini 키를 쓰면 브라우저가 코드 구조 요약을 Google로 바로 보냅니다. Anthropic·OpenAI 키를 쓰면 브라우저 제약 때문에 요약과 키를 Ropeman 프록시로 보내고, 프록시가 키를 저장하지 않고 제공자에게 넘깁니다.
- **추천 상황** — 더 큰 프로젝트, 더 정확한 분석 결과가 필요한 경우, 이미 LLM API 키를 보유한 개발자.

## WebGPU (브라우저 내장 AI, 실험적)

브라우저 안에서 LLM을 직접 실행합니다.

- **특징** — 브라우저 내장 LLM 런타임을 사용해 **완전 오프라인** 으로 동작합니다. 외부 네트워크 요청이 발생하지 않으며, 한 번 다운로드한 모델은 브라우저에 캐시돼 재사용됩니다.
- **요구사항** — WebGPU를 지원하는 최신 브라우저와 충분한 VRAM/RAM. 처음 실행할 때 모델 파일을 내려받습니다. 모델에 따라 약 400 MB에서 4.3 GB이고, 기본 모델은 900 MB입니다.
- **데이터 흐름** — 모든 추론이 사용자 기기 안에서 끝납니다. 어떤 데이터도 외부로 나가지 않습니다.
- **추천 상황** — 완전 오프라인 환경, 보안이 최우선인 경우, 성능 테스트가 가능한 고사양 기기. 소형 프로젝트부터 시도해 보시기 바랍니다.

## 코드 구조 요약 크기와 분석 품질

모든 AI 트랙에서 Ropeman은 원본 소스 대신 **코드 구조 요약(skeleton)** 만 모델에 전송합니다. 이 요약의 크기는 분석 품질과 속도, 그리고 사용 가능한 모델에 직접 영향을 줍니다.

- **클수록 정확하고, 작을수록 빠릅니다.** 요약이 크면 모델이 더 많은 함수·클래스·관계를 한 번에 볼 수 있어 다이어그램이 더 정교해지지만, 토큰 수가 늘어나는 만큼 응답 시간과 비용도 함께 증가합니다.
- **모델마다 한도가 다릅니다.** 같은 트랙이라도 선택한 모델의 컨텍스트 윈도우와 사양에 따라 처리 가능한 요약 크기와 응답 속도가 달라집니다. 특히 WebGPU 모드의 소형 모델은 다른 트랙보다 훨씬 작은 입력만 처리할 수 있습니다.
- **기본값과 조정.** 기본 한도는 **250 KB**이며, **설정 → 코드 구조 요약 크기 제한**에서 줄이거나 늘릴 수 있습니다. API 호출이 토큰 한도 오류로 실패하면 값을 줄이고, 더 정교한 분석이 필요하면 늘리세요. WebGPU에서는 약 12 KB 정도가 안정적입니다.

대부분의 사용자는 기본값으로 시작한 뒤, 결과 품질이 부족하면 단계적으로 늘려 보는 흐름을 권장합니다.

## 모드 바꾸기

헤더의 **분석** 버튼, 그 옆의 AI 배지, **설정 → AI 연결** 중 아무거나 누르면 **AI 아키텍처 분석** 창이 열리고, 모드마다 카드가 하나씩 있습니다. 트랙과 모델마다 분석 캐시가 따로 있어서 모드를 바꿔도 이전 결과가 지워지지 않습니다.

## 모드 선택 가이드

| 기준               | 데모  | API 키                                 | WebGPU           |
| ------------------ | ----- | -------------------------------------- | ---------------- |
| 설정 난이도        | 없음  | 낮음                                   | 낮음             |
| 비용               | 무료  | API 사용량                             | 무료             |
| 성능(모델 품질)    | 중    | 상                                     | 기기 사양에 따름 |
| Ropeman 서버 경유  | 예    | Gemini는 아니오, Anthropic·OpenAI는 예 | 아니오           |
| 오프라인 동작      | 불가  | 불가                                   | 완전             |
| 추천 프로젝트 크기 | 소~중 | 소~대                                  | 소               |

내 컴퓨터에 있는 폴더의 지도를 만들고 내 Claude Code나 Gemini CLI로 이름을 붙이려면 [ropeman.dev/bridge](https://ropeman.dev/bridge)의 브리지 모드를 쓰세요. 방법은 [브리지 설정](/docs/ko/bridge-setup)에 있습니다.

어떤 모드를 선택하든 **원본 소스 코드는 브라우저를 떠나지 않는다는 원칙**은 동일합니다. 자세한 데이터 흐름은 [보안 문서](/docs/ko/security)에서 확인할 수 있습니다.
